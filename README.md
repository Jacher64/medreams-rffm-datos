# medreams-rffm-datos

# Datos públicos RFFM para Medreams

Sólo resultados, calendario y clasificación oficiales del grupo de prueba. No contiene el código de la app, jugadores ficticios, notas, actas ni audios.

GitHub Actions consulta la federación cada 30 minutos y conserva la última lectura completa si falla la fuente. Las ejecuciones programadas pueden retrasarse.

La app consulta public/federation/latest.json con acceso público, sin credenciales.
